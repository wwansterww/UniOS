# Показ на защите: 5 минут

## Утром в день защиты (10 минут)

1. **Освежить данные на сайте**, чтобы дедлайны были «через 1 час», «завтра», а пары — сегодня:

   ```bash
   npm run demo:reset -- --yes
   ```

   Пароли, привязка Telegram и статистика `/metrics` сохраняются.
2. **Проверить сайт**: https://uni-os-theta.vercel.app открывается, вход работает.
3. **Телефон «студента»**: войти как `a.nurlanov@narxoz.kz`, в профиле Telegram — «Подключён».
   В чате с @UniOS_Narxoz_bot нажать «Сегодня» — бот должен ответить.
4. **Ноутбук «преподавателя»**: во втором окне (или инкогнито) войти как `a.saparova@narxoz.kz`.
5. **Пароли** — в `ACCOUNTS.local.md` (на этом компьютере, не в git). Держите файл открытым.

## Если что-то пошло не так

- **Нет интернета.** Запустите локально: `npm run dev -- -H 0.0.0.0` и откройте сайт по IP ноутбука.
  Бот локально молчит, пока у него стоит вебхук продакшена: это сделано специально, чтобы не отобрать бота у сайта.
  Покажите напоминания на странице «Уведомления».
- **Напоминание не пришло за минуту.** pg_cron отправляет раз в 5 минут. Пока ждёте, покажите «Оценки» или «Посещаемость».
- **Аккаунт заблокирован после неверных паролей.** Блокировка снимается через 15 минут. Эдвайзер (`g.seitova@narxoz.kz`)
  может сбросить пароль в разделе «Аккаунты».
